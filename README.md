# arvut.ch/awc — страница для дизайна

Копия страницы **[arvut.ch/awc](https://arvut.ch/awc/)** («AWC · ABM Working Computer — Die Buchhaltungsmaschine im Abo») для работы над дизайном. Живая страница на arvut.ch этим репозиторием **не управляется**: когда дизайн готов, Claude Саши переносит его на сайт.

**Превью:** https://arvut.github.io/awc-page/ — языки `de/` `fr/` `it/` `en/`.

## Что здесь

| Путь | Что это |
|---|---|
| `de/ fr/ it/ en/index.html` | страница на четырёх языках; стили — внутри каждого файла (`<style>`) |
| `index.html` + `awc.js` | входная страница: отправляет по языку браузера |
| `img/` | картинки Наташи: `awc-hero.(png|webp)` — ноутбук в шапке, `awc-scene.(jpg|webp)` — сцена у окна в разделе 05 |
| `logo.png`, `favicon.ico` | логотип Arvut |

Русской версии здесь нет намеренно: на сайте она скрыта. Дизайн перенесём на неё сами.

## Что меняем, а что нет

- ✅ **Дизайн** — всё визуальное: сетка, отступы, шрифты, цвета, анимации, картинки, порядок блоков, мобильная версия.
- 🛑 **Тексты не меняем.** Каждая формулировка выверена (последняя правка шапки — 16.10.2026, после двух проверок). Если хочется другое слово или короче — напиши предложение в описании Pull Request или Саше, текст поменяем мы сами на всех языках.
- 🛑 Не трогать в `<head>`: `canonical`, `hreflang`, `og:*`, `description`, `robots` — от них зависит, как страницу видят Google и превью ссылок в LinkedIn/WhatsApp.

## Правила сайта, которые дизайн должен выдержать

1. **JavaScript — только отдельным файлом** (`<script src="…">`), никакого кода внутри `<script>…</script>` и `onclick="…"`: arvut.ch блокирует встроенный JS (CSP `script-src 'self'`). Стили внутри `<style>` — можно.
2. **Внешнее — только шрифты Google Fonts.** Никаких CDN, библиотек и картинок с чужих сайтов: всё кладём в репозиторий.
3. **Телефон 390 px без горизонтальной прокрутки**, всё читается без зума.
4. Картинкам — `alt`, `width` и `height` (иначе страница прыгает при загрузке).
5. Немецкий — `ss`, не `ß`. Числа — с апострофом: `1'000`.
6. Бирюза Arvut: `#00777A` для текста и кнопок (`#009B9F` — только акцент, белый текст на нём плохо читается).

## Как работать

- Ветка на каждую итерацию → **Pull Request** в `main`. Превью обновляется само после мёрджа (GitHub Pages, 1–2 минуты).
- Локально: `python3 -m http.server 8000` в корне → `http://localhost:8000/de/`.
- Готово → скажи Саше: Claude перенесёт дизайн на arvut.ch (все языки, включая русский) и пришлёт ссылку.
